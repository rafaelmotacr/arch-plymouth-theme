# plymouth-arch

Plymouth theme for Arch Linux

> Tema **derivado** do tema Plymouth padrão do Manjaro
> ([`plymouth-theme-manjaro`](https://code.manjaro.org/artwork/plymouth-manjaro)),
> adaptado para exibir o logo do Arch Linux.

## Créditos

Este tema é um trabalho derivado do tema Plymouth padrão do Manjaro
([`plymouth-theme-manjaro`](https://code.manjaro.org/artwork/plymouth-manjaro)),
que por sua vez se baseia no tema `spinner` do próprio
[Plymouth](https://gitlab.freedesktop.org/plymouth/plymouth).
As principais alterações são a substituição do logo do Manjaro pelo logo do
Arch Linux e o ajuste das fontes.
